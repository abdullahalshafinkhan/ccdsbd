# ☁️ Cloudinary ব্যাকআপ — সম্পূর্ণ সেটআপ গাইড

এই গাইডটি অনুসরণ করলে প্রজেক্টের **সব ছবি, ফাইল এবং পুরো ডেটাবেসের JSON ব্যাকআপ**
Cloudinary-তে জমা থাকবে।

---

## ধাপ ১ — Cloudinary একাউন্ট ও Cloud name

1. [cloudinary.com](https://cloudinary.com/users/register/free) এ ফ্রি একাউন্ট খুলুন।
2. Dashboard এর উপরে **Cloud name** দেখাবে (যেমন `dxyz12abc`) — কপি করে রাখুন।

## ধাপ ২ — Unsigned Upload Preset তৈরি করুন

**Settings (⚙️) → Upload → Upload presets → Add upload preset**

| অপশন | মান |
|---|---|
| Preset name | `school_uploads` (যেকোনো নাম) |
| Signing Mode | **Unsigned** ← অবশ্যই |
| Folder | খালি রাখুন (কোড নিজে `school` ফোল্ডার পাঠায়) |

**Save** করুন।

## ধাপ ৩ — Resource list চালু করুন (⚠️ নতুন, খুব গুরুত্বপূর্ণ)

ক্লাউডে রাখা ব্যাকআপের **তালিকা দেখা ও সেখান থেকে Restore** করার জন্য এটি লাগবে:

**Settings (⚙️) → Security → Restricted media types** → `Resource list` এর পাশের
চেকবক্সটি **আনচেক** করুন → **Save**।

> এটি না করলেও ব্যাকআপ আপলোড হবে, শুধু "Cloudinary তে রাখা ব্যাকআপগুলো" তালিকাটি
> খালি দেখাবে এবং একটি এরর মেসেজ আসবে।

## ধাপ ৪ — দুই ফাইলে কনফিগ বসান

`admin.html` এবং `index.html` — **দুটো ফাইলেই** উপরের দিকে `APP_CONFIG` খুঁজে বসান:

```js
cloudinary: {
  cloudName: 'dxyz12abc',        // ধাপ ১ এর Cloud name
  uploadPreset: 'school_uploads', // ধাপ ২ এর preset নাম
  folder: 'school'
}
```

তারপর GitHub এ commit/push করুন — Cloudflare Pages নিজে থেকেই রিডিপ্লয় করবে।

⚠️ `index.html` এ কখনোই `adminKey` বসাবেন না।

## ধাপ ৫ — Admin Panel → Settings → Backup / Restore এ গিয়ে

1. **🚚 স্ক্যান করে Cloudinary তে সরান** বাটনে ক্লিক করুন — এতে আগে থেকে ডেটাবেসে
   base64 আকারে জমে থাকা সব ছবি/ফাইল Cloudinary তে চলে যাবে।
2. **☁️ Cloudinary তে ব্যাকআপ নিন** — প্রথম ব্যাকআপটি নিয়ে নিন।
3. **প্রতিদিন স্বয়ংক্রিয়ভাবে ব্যাকআপ** চেকবক্সটি চালু আছে কিনা দেখে নিন।

## 🆕 কী কী যোগ করা হয়েছে (কোড পরিবর্তন)

### `admin.html`

| ফিচার | কী করে |
|---|---|
| **ট্যাগিং** | প্রতিটি আপলোডে ট্যাগ বসে — ছবি/ফাইলে `school_asset`, ব্যাকআপে `school_backup`। এই ট্যাগ দিয়েই কোনো API secret ছাড়া ব্রাউজার থেকে ফাইলের তালিকা পড়া যায়। |
| **দৈনিক অটো-ব্যাকআপ** | অ্যাডমিন প্যানেল খোলার ৪ সেকেন্ড পর চেক করে — শেষ ব্যাকআপ ২৪ ঘণ্টার বেশি পুরোনো হলে নিঃশব্দে নতুন ব্যাকআপ আপলোড করে। Settings থেকে বন্ধ/চালু করা যায়। |
| **ক্লাউড ব্যাকআপ তালিকা** | Cloudinary তে রাখা সব ব্যাকআপ তারিখ ও সাইজসহ টেবিলে দেখায় — প্রতিটির পাশে ডাউনলোড ও **Restore** বাটন। |
| **এক ক্লিকে ক্লাউড Restore** | ফাইল ডাউনলোড করে আবার আপলোড করার দরকার নেই — সরাসরি ক্লাউড থেকে `/api/_restore` এ পাঠায়। |
| **base64 → Cloudinary মাইগ্রেশন** | পুরো ডেটাবেস স্ক্যান করে যেকোনো নেস্টেড ফিল্ডে থাকা `data:` URL খুঁজে বের করে, Cloudinary তে আপলোড করে, রেকর্ডে শুধু লিংক রেখে `replace-all` দিয়ে সেভ করে। প্রগ্রেস কাউন্টার দেখায়। |
| **ভালো এরর মেসেজ** | Cloudinary থেকে আসা আসল এরর কারণটি (যেমন preset ভুল) দেখায়। |
| **ইউনিক ফাইলনাম** | ব্যাকআপ ফাইলের নাম এখন `backup_2026-09-15T10-30-00-000Z` — দিনে একাধিক ব্যাকআপ নিলেও কোনোটি হারায় না (আগে দিনে একটার বেশি নিলে নাম মিলে যেত)। |

### `index.html`
পাবলিক সাইট থেকে আসা আপলোডেও (ভর্তি আবেদনের ছবি) একই `school_asset` ট্যাগ বসে,
যাতে সব ফাইল একই জায়গায় তালিকাভুক্ত থাকে।

### যা বদলায়নি
- D1 এখনো মূল ডেটাবেস, Cloudinary ফাইল-স্টোরেজ ও ব্যাকআপ গন্তব্য।
- Cloudinary কনফিগার না থাকলে আগের মতোই base64 fallback কাজ করে — কিছুই ভাঙবে না।
- `functions/api/[[path]].js`, `schema.sql`, `wrangler.toml` — কোনো পরিবর্তন লাগেনি।

## ⚠️ কিছু সীমাবদ্ধতা জেনে রাখুন

- **Unsigned preset পাবলিক।** `index.html` এ Cloud name ও preset নাম দেখা যায়, তাই
  তাত্ত্বিকভাবে যে কেউ আপনার একাউন্টে ফাইল আপলোড করতে পারে। ঠেকাতে Cloudinary
  preset এ **Max file size** ও **Allowed formats** সীমিত করে দিন।
- **`Resource list` খোলা মানে** `school_backup` ট্যাগের ফাইলের তালিকাও পাবলিক।
  ব্যাকআপে শিক্ষার্থীর তথ্য থাকে, তাই এটি সংবেদনশীল। বেশি নিরাপত্তা চাইলে
  ধাপ ৩ বাদ দিন — তখন তালিকা ফিচারটি বন্ধ থাকবে, কিন্তু আপলোড ও ম্যানুয়াল
  Restore (ফাইল আপলোড করে) ঠিকই কাজ করবে।
- **ফ্রি প্ল্যানে** ২৫ ক্রেডিট/মাস (≈২৫ GB স্টোরেজ+ব্যান্ডউইথ) — স্কুল সাইটের জন্য
  যথেষ্ট, তবে পুরোনো ব্যাকআপ মাঝে মাঝে Media Library থেকে মুছে দিলে ভালো।
- **Cloudinary Cloudflare D1 এর বিকল্প নয়** — লাইভ ডেটা D1 তেই থাকে, Cloudinary
  শুধু ফাইল ও ব্যাকআপের কপি রাখে।
